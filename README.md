# FlowSync — Adaptive Traffic Signal Control

FlowSync is a browser-based traffic intersection simulator that compares fixed-time and adaptive traffic signal control.

## Features

- Animated four-way intersection
- Fixed-time and adaptive signal modes
- Multiple traffic scenarios
- Dynamic traffic-pressure-based phase selection
- Empty-lane skipping
- Maximum-wait / starvation prevention
- Live queue, waiting-time, throughput and delay metrics
- Controller decision log
- Queue-history visualization
- Fixed vs. adaptive comparison using a consistent traffic seed
- Runs directly in the browser with no server or package installation

## Run locally

Open `index.html` in a modern browser.

## GitHub Pages

This project is static, so it can be deployed with GitHub Pages:

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for the Pages deployment.

## Project structure

The main entry point is `index.html`. Any additional project assets included in this repository are kept in their original folders.
